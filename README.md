# .github
FlyGACA organization profile and default community health files

## What is here

| Path | What it is |
| --- | --- |
| `profile/README.md` | The organization profile shown on github.com/FlyGACA. |
| `ISSUE_TEMPLATE/`, `pull_request_template.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Default community health files, inherited by every repository that has no file of its own. |
| `workflow-templates/` | Starter GitHub Actions workflows (Node, Python) offered when a repository adds a workflow. |
| `starter-kit/` | What a new repository starts from: `CLAUDE.md`, Claude Code settings, a git guard hook, content rules and a review workflow. [Details](starter-kit/README.md). |
| `rulesets/` | A draft branch ruleset for the default branch, not applied. [Details](rulesets/README.md). |
| `CLAUDE.md` | The rules for working in this repository. |
