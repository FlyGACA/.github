# Getting help

- **Using flygaca.com or Captain Adel?** Visit [flygaca.com](https://flygaca.com) or email **i@flygaca.com**.
- **Found a bug?** Open an issue in the relevant repository using the bug report template.
- **Have an idea?** Open a feature request issue.
- **Security problem?** Follow the [security policy](SECURITY.md) — please don't post it publicly.
